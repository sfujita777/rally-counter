# 連続ラリーカウンター — 本番一式（PHASE 1）

四国フレスコボール協会の「連続ラリーカウンター」本番版。静的HTML1枚（`index.html`）＋
中央台帳（Google Apps Script `gas.gs`）で、**各地の端末から記録 → 中央に集約 → ランキング表示**を実現する。

思想の正本＝[[../../../concepts/スポットライトの民主化-連続ラリーカウンター]]
設計の正本＝[[../連続ラリーカウンター-本格制作仕様]]

- 本番URL（入口＝ランキング）：https://sfujita777.github.io/rally-counter/
- 記録用URL：https://sfujita777.github.io/rally-counter/?mode=count
- 大画面（キオスク・当面保留）：https://sfujita777.github.io/rally-counter/?mode=board
- 公開リポジトリ：https://github.com/sfujita777/rally-counter （Public / GitHub Pages）

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。無指定＝入口ランキング／`?mode=count`＝記録／`?mode=board`＝大画面 |
| `gas.gs` | 中央台帳。フォーム回答シートにバインドしWeb App公開（doGet=一覧／JSONP） |

通信は **JSONP**（script タグ）。GitHub Pages など別ドメインの静的ページから GAS を叩くと
`fetch` はCORSで弾かれるため、CORSの要らない JSONP を採用している。

## 記録〜集約のモデル（承認制は廃止・2026-11-23）

1. **記録端末（`?mode=count`）**：ペアを登録し、制限時間内に連続ラリーをカウント。各記録は端末のローカルに溜まる。
2. **1日の終わりに一度だけ送信**：画面下の **①本日分をまとめてコピー**（改行区切りの複数行）→ **②送信フォーム**（Googleフォーム「段落・1項目」）に貼り付けて1回送信。
3. **GAS** が回答シートを読み、改行で1記録ずつ・`|` で列に分解して一覧（JSON）を返す。
4. **入口ランキング**が15〜30秒ごとにGASを読んで表示（＝まとめ送信後に反映・非リアルタイム）。

承認フローは無い。送信者本人が内容を確認して送る前提。GAS側で上限チェック（連続回数1〜3000／文字数40字／異常値は破棄）。

## 記録のルール（制限時間内に何度も挑戦）

制限時間（1分 or 5分）は**流しっぱなし**。その時間内で何度でもラリーに挑戦できる。

- **タップ ＋1**：落とさず続いた1打ごとに押す（＝連続回数）。
- **落とした ＋1（0に戻す）**：ラリーが途切れたら押す。**連続回数を0に戻し、タイマーは継続**。同時に**落球数を+1**。
- **ストップ＆記録 / 時間切れ**：その時間内の **ベスト（最高連続回数）** を記録する。
- 画面には「現在の連続（大）」＋「**ベストN回 ・ 総打数N ・ 落球N**」を表示。
  - **総打数** ＝ その時間のタップ総数（落球でリセットしない）。
  - **落球数** ＝「落とした」を押した回数。
- 10本ごとに音＋掛け声（各節目5パターンからランダム・100超はレジェンド枠）。
- 入力補助：Space/Enter キー、一部のBluetoothリモコンでもカウント可。

### 掛け声の声（読み上げ）
- 画面の **声** ドロップダウンで端末の日本語音声から選択。先頭の **「なし（読み上げオフ）」** で無効化（初期値＝なし）。選択は端末に保存。
- もっと自然な声にしたい時は、端末の設定で **Siri／拡張の日本語音声** を追加するとそれが選べる。

## セットアップ / 更新手順

### ① 中央台帳（GAS）
1. フォーム回答が入るスプレッドシートを開く → 「拡張機能 → Apps Script」
2. `gas.gs` の中身を全部貼り付けて保存
3. **初回デプロイ**：「デプロイ → 新しいデプロイ → ウェブアプリ」／実行：**自分**／アクセス：**全員** → `/exec` URL を発行（初回は承認ダイアログを許可）
4. **更新時**：`gas.gs` を貼り直して保存 →「デプロイ → デプロイを管理 → ✏️編集 → バージョン：新バージョン → デプロイ」。**URLは変わらない**。
5. `SOURCE='form_paste'`／`PASTE_SHEET`（回答シート名）／`PASTE_COL`（貼り付け列）を環境に合わせる。

### ② アプリにURLを設定（`index.html` の `CONFIG`）
- `GAS_URL` … ①の `/exec` URL（設定済み。`?api=<exec URL>` で一時上書きも可）
- `FORM_URL` … 送信用Googleフォーム（段落・1項目）のURL（設定済み）

### ③ GitHub Pages で公開 / 更新
- `gh` CLI 未導入のため **GitHub Web UI** で行う：
  1. https://github.com/sfujita777/rally-counter を開く → `index.html` → ✏️ Edit
  2. 中を全消し → `index.html` の全文を貼り付け → **Commit changes**
     （または一覧で **Add file → Upload files** に `index.html` をドラッグ → Commit）
  3. 数十秒で https://sfujita777.github.io/rally-counter/ に反映

## 設定（`index.html` の `CONFIG`）
- `CLUBS` … 所属クラブ：**SFC（香川）／KFC（高知）／UFC（徳島）／SNFC（愛媛）／その他**
- `CATEGORIES` … **男子／女子／ミックス／キッズ（5m）**
- `WITNESSES` … 立会代表（`official:true` が公式記録の立会資格）＋「立会なし（参考記録）」
- `DURATIONS` … **1分 / 5分**（この2部門でランキングが分かれる）
- `AUTO_SEND` … 既定 **false**（＝終了時にまとめ送信）。true で記録ごとGASへ自動送信（即反映）
- `BOARD_REFRESH_MS` / `BOARD_ROTATE_MS` / `BOARD_TOP_N` … 大画面の更新間隔・ローテ・表示件数

## 記録のデータ構造
1記録 ＝ **選手ごとにクラブ＋名前**（ペアはクラブをまたいでOK）× カテゴリ × 時間 × 連続回数（＋落球数・総打数）。
- クロスクラブのペア（例：UFC多田 ／ SFC藤田）は、**クラブ別集計で両クラブの取り組みとしてカウント**。

### コピー1行＝シート列（`|` 区切り・この順／全12列）
```
日時 | クラブ1 | 名前1 | クラブ2 | 名前2 | カテゴリ | 時間(分) | 連続回数 | 立会代表 | 区分(公式/参考) | 落球数 | 総打数
```
- 落球数＝11列目・総打数＝12列目。**旧10列の行も後方互換**で読める（落球/総打＝0扱い）。
- 「まとめ送信」は上記の行を**改行区切りで複数行**まとめて1回送信する。

## ランキングの見え方
- **入口（無指定）＝ランキング**：上部に **1分部門／5分部門** タブ＋ **総合／男子／女子／ミックス／キッズ（5m）** タブ。**連続ラリー回数（＝時間内のベスト）順**。各行に所属・カテゴリ・**総打数**も表示。
- **大画面（`?mode=board`・当面保留）**：総合／カテゴリ／クラブ別を自動ローテーション。クラブ別は各クラブの参加人数・記録数・最高回数。
